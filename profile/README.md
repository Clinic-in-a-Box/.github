# Clinic in a Box

Clinic in a Box is a clinic management platform designed to help independent and growing clinics manage their digital operations from one system.

The platform is being built to support:

- Clinic websites
- Online booking
- Patient and appointment management
- Staff administration
- Communications
- Payments
- AI-assisted workflows
- Multi-clinic onboarding and management

## Platform

The core application is maintained in the private `clinic-in-a-box-platform` repository.

Clinic in a Box is currently under active development.
